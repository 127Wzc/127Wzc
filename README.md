### Featured Projects

- **[Yui Chat](https://github.com/127Wzc/yui-chat)** — Agent runtime for QQ bots: multi-provider protocol adapters, a real tool loop, MCP client, layered memory with daily distillation, hybrid full-text + vector retrieval. `TypeScript` `SQLite` `sqlite-vec` `Vue 3`
- **[ImgTag](https://github.com/127Wzc/ImgTag)** `⭐ 10` — Self-hosted photo library: vision-model tagging, semantic search on pgvector, async analysis pipeline, MCP service, multi-endpoint S3 storage. `FastAPI` `Vue 3` `pgvector`
- **wan** `private` — Automation runtime behind one config snapshot: task daemons with retry/backoff, proxy pool rotation, per-run artifacts, WebSocket log stream. `Python` `FastAPI` `SQLAlchemy 2`
- **Enterprise backend** `private` — Java microservices: Spring Cloud service split, MyBatis-Plus with slow-query and index work, distributed locks, security auditing, file service on object storage. `Java` `Spring Boot` `MySQL` `Redis`
